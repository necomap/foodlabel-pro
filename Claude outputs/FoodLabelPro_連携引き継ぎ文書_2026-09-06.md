# FoodLabel Pro 引き継ぎ文書（HACCP・在庫アプリとの連携機能について）

作成日時: 2026-09-06

このアプリ（FoodLabel Pro）の個別機能は別チャットで進めていますが、この文書は**HACCPアプリ・在庫アプリとの3アプリ連携（印刷時の自動在庫差し引き）機能に限定**した引き継ぎです。実装自体は別セッションで完了していますが、動作確認・本番反映がまだの状態です。この文書を新しいチャットの最初に添付してください。

---

## 1. 機能概要

FoodLabel Proでラベルを印刷すると、印刷画面の「在庫を差し引く」チェックボックス（デフォルトON、前回値はブラウザに保存）がONの場合、印刷枚数に応じて材料の在庫を自動で差し引きます。

- **設定画面で「HACCP連携用店舗コード」が設定されている場合**: HACCP経由で差し引く。HACCP側の「製造記録」にも自動で1件記録が残る仕様。HACCPが在庫アプリと連携済みならそちらの在庫を、未連携ならHACCP自身の在庫を差し引く。
- **HACCP未連携で「在庫アプリ連携用ユーザーID」のみ設定されている場合**: 在庫アプリへ直接、材料在庫の差し引き＋完成品在庫の増加を行う。
- **どちらも未設定の場合**: 何もしない（印刷自体は通常どおり成功する）。

この機能は**プロプラン限定**です（`lib/plan-limits.ts`の`canUseStockSync`フラグ、pro/adminのみtrue）。「スタンダードでも使えるようにして合わせて課金する人を増やす」という案も出ましたが、今回は**様子見でプロ限定のまま維持**することに決まっています。

## 2. 店舗コード・IDについて（確認済み・変更なし）

「HACCP連携用店舗コード」は識別子であり秘密情報ではありません。実際の認証は共有シークレット（後述の環境変数）をヘッダーに載せる方式のため、店舗コードやユーザーIDそのものが人に見られても連携の安全性には影響しません（この点はユーザーからも質問があり、調査の上で問題ないと回答済みです）。

## 3. 変更済みファイル（このアプリ側、PCへ書き込み済み・git未コミット）

- `prisma/schema.prisma` — `User`に`inventoryUserId`・`haccpStoreCode`（ともに任意項目）を追加
- `lib/plan-limits.ts` — `canUseStockSync`フラグ追加（pro/adminのみtrue）
- `lib/stock-sync.ts`（新規） — 印刷後にHACCPまたは在庫アプリへ差し引きリクエストを送る`deductStockForPrint()`
- `app/api/labels/generate/route.ts` — 印刷完了後に`deductStockForPrint()`を呼び出し、結果を`data.stockSync`としてレスポンスに含める
- `app/api/labels/print-stats/route.ts` — `canUseStockSync`・`stockSyncConfigured`をレスポンスに追加（印刷画面のチェックボックス表示制御用）
- `app/api/user/profile/route.ts` — `inventoryUserId`・`haccpStoreCode`の読み書きに対応
- `app/dashboard/settings/page.tsx` — 「印刷時の在庫自動差し引き」欄（HACCP連携用店舗コード・在庫アプリ連携用ユーザーID入力欄）を追加
- `app/dashboard/labels/page.tsx` — 「在庫を差し引く」チェックボックス・印刷結果のトースト通知を追加

## 5. ユーザー側の必須作業

1. **DBスキーマ反映**: このフォルダで`npm run db:push`を実行（`User`に`inventoryUserId`・`haccpStoreCode`列を追加するコマンド）。
2. **環境変数（Vercel）**:
   - `FOODLABEL_SYNC_SECRET`: 新規に決めた値を、**このアプリとHACCP両方のVercelプロジェクト**に同じ値で設定。
   - `INVENTORY_SYNC_SECRET`: 既存の値（HACCPと在庫アプリの間で使っているもの）を、**このアプリのVercelプロジェクトにも追加**（在庫アプリへ直接連携する場合のみ必要。HACCP経由のみで使うなら省略可）。
   - 環境変数はVercelに設定しただけでは反映されません。設定後、GitHub Desktopでコミット→push→Vercel自動デプロイまで行ってください（Redeployボタンのみでは不可）。
3. **設定画面での入力**: 設定画面の「印刷時の在庫自動差し引き」欄に、「HACCP連携用店舗コード」（HACCP管理画面に表示）または「在庫アプリ連携用ユーザーID」を入力・保存。
4. **品名の違いがある場合**: HACCP側の「品名マッピング」設定画面で、レシピで使っている材料名（foodlabel-pro側の名前）も合わせて登録すると精度が上がります（任意）。
5. **実際に試す**: ラベルを1枚印刷し、「在庫を差し引く」にチェックが入っていることを確認して印刷 → 材料在庫が減っているか、（HACCP経由の場合は）HACCPの製造記録に自動で1件増えているかを確認。
