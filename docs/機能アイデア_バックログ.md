## 2026-09-13 追加分

食品表示ラベル管理という領域で、類似アプリ・近い業種のツールでよく使われている機能を調査し、
FoodLabel Proへの追加候補として整理したもの。

### 原価・利益まわり

- **ロット単位でのトレーサビリティ強化**
  現状は`Label.lotInfo`でロット番号を扱っているが、原材料の仕入ロットと紐づけて
  「この製品のこのロットにはどの仕入ロットの材料が使われたか」まで追跡できるようにすると、
  回収（リコール）対応の際に範囲を絞り込みやすくなる。

### 表示・コンプライアンスまわり

- **QRコードでのアレルゲン・原材料情報の公開**
  ラベルにQRコードを印字し、読み取るとオンラインでアレルゲン・原材料の詳細を確認できるページを表示する機能。
- **多言語ラベル対応**
  インバウンド需要や輸出を見据えた英語表記等の切り替え機能。
- **JAN/GS1バーコードの自動生成**
  商品コードからバーコード画像を生成し、ラベルに印字できるようにする。

### 運用・現場まわり

- **複数人での承認フロー**
  栄養士・責任者などがダブルチェックし、承認履歴が残る仕組み。表示ミスの防止に有効。
- **ラベルの変更履歴・バージョン管理の可視化**
  いつ・誰が・どの項目を変更したかを一覧できる画面（現状DBに履歴があっても画面上で追いにくい場合の改善）。
- **賞味期限・価格改定の通知機能**
  賞味期限が近い食材や、仕入単価が変更された食材がある場合にダッシュボード等で知らせる。

### 検討済み・対応不要と判断したもの

- **原価率の自動計算** → 調査の結果、`app/api/recipes/[id]/route.ts`ですでに実装済みと確認。
  レシピの材料行で原価単価を明示入力していない場合は、食材マスタ側の仕入単価（`Ingredient.unitPrice`）
  の変更が閲覧のたびに自動反映される（保存し直す必要はない）。逆に、そのレシピの材料行で
  原価単価を明示的に入力・上書きしている場合はその値が優先され、マスタ側の変更では上書きされない
  （意図的な入力値を壊さないための仕様）。追加対応は不要。

## 2026-11-10 追加分（類似サービス調査：ウラベル／スマート食品表示／そうけんくん／Food Label Maker）

### 無料で追加できるもの → 実装予定（`docs\引き継ぎ文書_20261110.md` のタスク）
- アレルゲン一覧表（全商品×28品目、店頭掲示・PDF）
- 商品規格書のPDF出力（卸先向け）
- 栄養強調表示の判定（「低カロリー」「たんぱく質たっぷり」等）
- POP・プライスカード印刷
- 英語ラベル用の店名・住所（店舗設定に英語欄）

### 課金ユーザーが増えて元手ができたら作る（AI利用料がかかるもの）
- **手書きレシピ・メモの写真からレシピを起こす**（ユーザー要望・優先度高）
  撮影 → AIで材料名と分量を読み取り → 食材マスタと照合した確認画面 → レシピとして保存。
  読み取り結果は必ずユーザーが確認してから保存する。有料プラン限定＋月の回数上限で原価を抑える想定
- **仕入先の規格書（PDF・写真）を読み取って食材登録**
  原材料・アレルゲン・添加物・栄養成分を抽出して食材マスタに登録（確認画面必須）
